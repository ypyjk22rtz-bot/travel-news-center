# Travel News Center AI

Aplicație editorială independentă pentru monitorizarea surselor oficiale de călătorie, generarea asistată de AI și publicarea controlată pe Travelistul.com.

## Principii

- complet separat de Portal Travelistul și de repository-ul `travelistul-ai`;
- publicare implicită ca draft;
- aprobarea umană este obligatorie înainte de publicarea live;
- integrarea finală se face prin WordPress REST API către Travelistul.com.
